## 🎨 Brand Identity & Colour Distribution
- **Burgundy Red (`#A71930`)**: ~20% (Headings, primary action buttons, footer, monogram emblems)
- **Soft Rose Pink (`#D9829B`)**: ~10% (Subtle highlights, badge accents, borders, decorative icons)
